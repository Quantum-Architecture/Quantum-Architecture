### QEC - Quantum Excellium Core
QEC is presented publicly as a layered governance and execution architecture:

`Intent -> Policy & Governance -> Orchestration -> Controlled Execution -> Runtime Integrity -> Evidence`

Public materials focus on interfaces, capability boundaries, auditability and integration patterns rather than proprietary implementation logic.

### Specialised AI systems
Public work includes **QE Fashion AI Agent Pro (QE-FAS)**, designed around brand-signed, third-party-verifiable product passports and whole-collection processing.

### AI Worlds
Three experimental environments designed for AI models themselves:

- **Ludonirium** - experience, structured interaction and replay
- **Parcivium** - more distinct possibilities under resource constraints
- **Syngnosium** - structured human-model cooperation

These environments use protocol-based evaluation and explicit limits. They do not claim AI consciousness or sentience.

### Interactive systems
Quantum Excellium also maintains a public Game Division and selected interactive demonstrators used to present ideas, constraints and system behaviour without exposing proprietary source code.

## Controlled disclosure

The public GitHub layer is designed to be **substantive but non-enabling**.

Published:
- functional purpose;
- architecture at public abstraction level;
- demonstrable verification principles;
- public interfaces and boundaries;
- selected evidence and examples.

Not published:
- unpublished source code;
- patent-enabling implementation details;
- private prompts or orchestration logic;
- internal thresholds, weights or secret parameters;
- confidential customer or partner information;
- defence-sensitive or otherwise restricted material.
